# Bamboo — Insurance Platform

وب‌اپ بامبو (PWA): صدور بیمه ثالث و بدنه، مدیریت حادثه و خسارت.
ساخته‌شده با React + TypeScript + Vite. طراحی مرجع: `docs/prototype/bamboo-v8.html`.

## اجرا

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # خروجی در dist/ (شامل service worker و manifest)
npm run preview
```

## ساختار

```
src/
  api/          types.ts (مدل داده) + mock.ts (بک‌اند ساختگی، با همان امضای API واقعی)
  store/        app.ts (state کل اپ با zustand) · ui.ts (toast، شیت ورود) · seed.ts (داده‌ی نمونه)
  components/   اجزای مشترک: Icon، Sheet، OtpInput، IrPlate، …
  layout/       AppShell، TopBar (منو و تم)، BottomNav
  features/     هر بخش اپ در پوشه‌ی خودش (home، issuance، profile، wallet، …)
  lib/          فرمت اعداد فارسی، تاریخ شمسی، پلاک
  styles/       legacy.css (استایل پروتوتایپ، بدون تغییر) · app.css (استایل‌های جدید)
```

**اتصال به بک‌اند:** صفحه‌ها فقط توابع `src/api/mock.ts` را صدا می‌زنند. وقتی API ساخته شد،
همین توابع با فراخوانی HTTP جایگزین می‌شوند و صفحه‌ها تغییری نمی‌کنند.
پرداخت، پیامک، شاهکار، سنهاب و تارا/دیجی‌پی هم از همین لایه رد می‌شوند.

**حالت‌های نمایشی:** از منو → «حالت‌های نمایشی» می‌شود خطاهای PRD (شاهکار، کندی سنهاب، قطعی بیمه مرکزی و …) را روشن کرد.

## تغییرات نسبت به پروتوتایپ (کوتاه‌تر کردن مسیر)

- صدور ثالث: «نمایش اطلاعات خودرو» داخل مرحله‌ی قیمت ادغام شد؛ برای کاربر واردشده مرحله‌ی OTP حذف است (۵ → ۳ یا ۴ مرحله).
- کد OTP با وارد شدن رقم چهارم خودکار تایید می‌شود.
- موجودی کیف پول در پرداخت به‌صورت پیش‌فرض اعمال می‌شود.
- مسیرها URL واقعی دارند (دکمه‌ی بازگشت مرورگر و لینک مستقیم کار می‌کند).
- فونت وزیرمتن داخل اپ بسته‌بندی شده (بدون وابستگی به Google Fonts).
